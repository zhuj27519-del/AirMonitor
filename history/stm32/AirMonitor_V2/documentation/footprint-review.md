官方 API 的组件子焊盘 setter 曾显示成功但重开后回退。最终通过官方原生 TPcbPad / EPadConnect 格式，在工程内嵌封装资源中持久化两个 USB 铜盘宽度和两个散热盘直连设置。两份原生文档均同步修改，重开读回和保存后的文件检查通过，见 `verification/p1-native-footprint-edits.json`、`p1-native-readback.json`。没有修改供应商云库，也未降低 DRC 间距。

库中的部分焊盘关闭了自动钢网扩展并使用独立助焊层图形。最终钢网开口必须按导出的 Paste 层复核，尤其 QFN EP；不能仅看焊盘 expansion 数字判定有无焊膏。此项尚未获得装配厂确认。
