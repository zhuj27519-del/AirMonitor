## 已关闭问题及复核方式

P0 铜边界使用的矩形坐标约定导致区域偏离板框。改成明确闭合顶点后 GUI 可以填铜。重新布线后的首次填铜后台停滞，停止并重开本任务编辑会话后成功；最终以 filled 对象、原生 DRC 和 Gerber 区域同时证明完成。未伪造铜层填充数据。

原理图/PCB 曾出现一项 Netlist Error。独立逐引脚比较没有分网差异，发现旧器件的 Channel ID 元数据未同步；通过原生 importChanges 同步后，重开及最终 DRC 均通过。未隐藏该项检查。

组件子焊盘 API setter 曾未能跨重开持久化。按官方 TPcbPad / EPadConnect 格式修订工程内嵌封装资源，两份原生文档同步；再重开核验 A9/B9=0.76mm、U2 tab4/U3 EP21=DIRECT，并重新补铜。证据为 p1-native-footprint-edits.json 与 p1-native-readback.json。

## 制造前仍需关闭

1. 电源：OVP 名义 5.3757V；含器件阈值、漏电和初始电阻公差为 5.2540–5.4978V，未计电阻温漂和过冲。不能保证传感器始终低于 5.5V；需更严格阈值电路或实际模块允许瞬态范围及资格测试。测背光电流、PMS 启动、PTC 压降、LDO/eFuse 温升。
2. 装配：依据各厂家图纸完成所有封装/极性/钢网/底面旋转的终审。U3 库外围焊盘与 TI 示例不同，不能把 DRC 0 当作装配验收。
3. 线束/机械：八针电气接口已按用户要求确定，不再将“必须改回十针”作为前提；传感器端用配套线，21VOC 插座仍需实物核对。验证显示支柱、线缆和外壳，保持传感器气流隔离。
4. 固件/样机：捕获实际八针模块 UART 帧后核对现有 32 字节解析器；执行 bringup.md。当前仅有主机解析器测试，没有真实模块功能验证。

以上限制是具体工程未验收项，不是由已解决的 USB/补铜问题推导的泛泛警告。任何后续电路或封装变更都要重新布线/补铜、ERC/DRC、网表比对和制造导出。
